Проект "Трекер привычек"

##Описание: созданы приложения habits и users на основе DRF:
1. Данные приложения зарегистрированы в настройках (config\settings.py\installed app)
2. Созданы модели Habit и User
3. В файле habits/validators.py реализован валидатор, который учитывает следующие условия:
   - исключены одновременный выбор related habits и  указание reward;
   - время выполнение не более 120 секунд;
   - в related habits попадают только приятные привычки
   - у приятной привычки отсутствует вознаграждение
   - привычка выполняется 1 раз в 7 дн.
4. В файле paginators.py добавлена пагинация для вывода списка привычек
5. Установлены права доступа в файле habits/permissions.py. Каждый пользователь имеет доступ только к своим привычкам по мехунизму CRUD
6. В файле habits/tasks.py реализована работа с отложенными задачами для напоминания о привычках в определенное время, сервис интегрирован с мессенджером Telegram 
7. Для проекта настроен CORS и вывод документации (эндпоинты).

##Установка:
1. Клонируйте репозиторий git@github.com:Ekaterina-RA/Tracker.git
2. Установите зависимости pip install, которые указаны в файле requirements.txt 
3. Тестирование. Отчет по покрытию тестами находится в файле .coverage
